# Husvisning

En enkel 3D-visning i webbläsaren där man kan gå runt i ett enplanshus, ute och inne.

- **Dator:** WASD/piltangenter för att gå, musen för att titta, Shift för att gå fortare.
- **Mobil/surfplatta:** spaken nere till vänster för att gå, dra på skärmen för att titta.
- **Visa uppifrån:** dockskåpsvy utan tak.

Byggd med [three.js](https://threejs.org/). Modellen ligger i `modell/`.
